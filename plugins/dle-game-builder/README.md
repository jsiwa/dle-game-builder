# DLE Game Builder Plugin

This plugin packages the `dle-game-builder` Agent Skill for Codex, ChatGPT, and Claude Code. It uses one shared skill implementation with host-specific manifests and no external service dependency.

Full installation, usage, development, and security documentation is available at:

https://github.com/jsiwa/dle-game-builder#readme

In Codex, invoke the skill as `$dle-game-builder`. In Claude Code, a standalone installation uses `/dle-game-builder`; a plugin installation uses `/dle-game-builder:dle-game-builder`.
